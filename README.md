# 🍽️ Restaurant Recommendation System

## 📌 Project Description

This project is a Restaurant Recommendation System that helps users find suitable restaurants based on preferences. It provides an easy-to-use interface to explore restaurants and view details.

## 🚀 Features

* View list of restaurants
* Filter/search restaurants
* User-friendly interface
* Responsive design

## 🛠️ Technologies Used

* React.js
* JavaScript
* HTML
* CSS / Bootstrap

## 📂 Project Setup

1. Clone the repository:

   ```
   git clone https://github.com/sanikasavant2004-blip/Restaurant-Recommendation-app.git
   ```
2. Navigate to project folder:

   ```
   cd Restaurant-Recommendation-app
   ```
3. Install dependencies:

   ```
   npm install
   ```
4. Run the project:

   ```
   npm start
   ```
